# 2. Public `/students` page / class-materials section

This needs special clarification because the **original plan and later architecture are different**.

Originally, `/students` was deliberately created as a public class-material browser:

```text
/students
    ↓
Class 1–10
    ↓
class materials
    ↓
Preview / Download
```

The original blueprint explicitly planned this as a public Phase-1 feature. 

But the current ERP architecture recognizes that this is not the right long-term learning-resource model: `class_materials` is still public-read today, while authenticated learning resources are a future separation. 

### Our current direction

🔴 **Remove/deactivate the public student/materials experience from the public website.**

That means:

* remove **Students** from public navbar
* remove public `/students` page from normal navigation
* do not expose class materials publicly
* remove public preview/download access
* keep the underlying material capability available for the ERP/staff workflow
* do **not** delete the database table yet
* do **not** delete existing test material data

### Database/security side

Later, once the replacement learning-resource model is established:

```text
public class materials
        ↓
authenticated school resources
```

The public-read RLS should be removed.

**Important:** don't drop `class_materials` simply because `/students` disappears. The table still supports the current staff/material workflow.
